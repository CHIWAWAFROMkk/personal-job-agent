个人求职 Agent 桌面版 1.0.0rc1
================================

怎么打开
--------
1. 请先完整解压 ZIP，不要直接在压缩包里运行。
2. 双击 PersonalJobAgent.exe，或双击 Start-PersonalJobAgent.cmd。
3. 按首页引导上传真实简历，填写目标岗位和工作城市。
4. 添加一个岗位：粘贴招聘信息并核对识别结果，或直接填写公司、岗位和要求。
5. 进入岗位准备简历，核对材料后由本人在招聘网站投递。验证码也由本人在网站填写。

照片、通勤、AI、搜索和地图配置可以稍后补充，不影响开始使用本地基础功能。

不填写 API 时，也可以把岗位或 JD 手动导入，或让本机上的 Codex 等助手直接协助更新岗位库与材料；API 主要用于软件脱离助手后独立批量运行。

这台电脑不需要安装 Python。

个人数据保存在哪里
------------------
程序、简历、API Key 和岗位库彼此分离。每位 Windows 用户的数据保存在：

%LOCALAPPDATA%\PersonalJobAgent

把程序文件夹复制给别人不会带上你的简历、密钥、岗位库或投递记录。删除或更新程序也不会自动删除个人数据。

投递页面组件
------------
标准桌面投递辅助使用系统默认浏览器，不需要额外 Chromium。
只有使用可选的浏览器测试或命令行辅助功能时，才可能需要运行：

Install-Optional-Browser.cmd

它会下载浏览器运行组件。程序只打开岗位页面，并在资源管理器中选中岗位专属 PDF；登录、作品集、表单填写、简历上传和最终提交全部由本人完成。

常见问题
--------
- 如果窗口无法显示，请安装或修复 Microsoft Edge WebView2 Runtime。
- 启动诊断日志位于：%LOCALAPPDATA%\PersonalJobAgent\logs\desktop.log
- 换电脑时，如需迁移自己的资料，请复制整个 %LOCALAPPDATA%\PersonalJobAgent 文件夹，并妥善保管其中的 API Key。
- 本软件是本地工具，不会替你保证招聘结果，也不会自动编造经历。
- API 用量页记录的是本软件本月成功请求；服务商真实余额以其官方控制台为准。
- 云端请求如超时或响应不明，用量页会占用一个预留名额并提示核对，避免重复付费请求越过本机月度上限。
- 实站 AI 自动代填已暂停；可在岗位里预览待填字段，随后本人在招聘网站核对并完成操作。

备份、升级与恢复
--------------
先保存并关闭程序，再复制整个个人资料目录到新的带日期备份文件夹。
升级时将新 ZIP 解压到新文件夹，保留旧程序及数据备份，不覆盖旧程序目录。
程序会识别并恢复中断的用户切换；若提示恢复失败，保留现场，不删除恢复标记或旧资料。
完整步骤、首次使用和故障处理见同目录 USER_GUIDE.md。
