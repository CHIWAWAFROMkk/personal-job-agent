# Code of Conduct

We are committed to a respectful, harassment-free collaboration space. Be kind,
specific and constructive; critique ideas and code rather than people. Do not publish
another person's private information, credentials or application history.

Maintainers may edit or remove abusive, discriminatory, threatening, spammy or
privacy-violating content and may restrict participation when needed. Report sensitive
conduct or privacy issues through GitHub's private vulnerability reporting flow; use a
public Issue only when the report contains no sensitive information.

This policy applies in repository Issues, Discussions, pull requests and other project
spaces.
