## 修复闭环

修复了用户切换中断混用资料、验收跳过核心步骤、JD 同行字段误识别、姓名误作经历、重复与内部占位进入简历、联系方式缺失，以及资格事实误删。独立复核找到的源码隐藏目录漏扫已修复并重跑探针。

全量回归进一步发现空摘要导致事实对照整体不可用，现仅省略空的可选摘要行；至少一条非空经历、有效且已确认的来源、云端事实审核和旧审批失效规则继续保留。原失败门禁测试未放宽。QA 函数退出后恢复环境，旧桌面测试更新为所有必需步骤必须运行。

实际 ZIP 验收发现两个资源缓存包含开发路径；最终构建排除缓存后重新打包并重复实际包验收。首次打包版流程脚本未关闭自动打开的审阅框，现通过正常 UI 关闭后切换岗位，未强制穿透弹窗。

## 未覆盖的边界

没有真实申请、付费 API 消耗、实站代填或真实招聘反馈。本轮没有逐项人工操作系统外部 PDF 阅读器、招聘站点及所有原生窗口；原生证据是 WebView DOM 自动操作、实际 PDF 字节与独立 PDF 渲染。物理断电、硬件损坏、外部程序任意并发修改和旧版本无恢复记录的事故仍需独立评估。发行文件未取得代码签名或第三方安全认证。
