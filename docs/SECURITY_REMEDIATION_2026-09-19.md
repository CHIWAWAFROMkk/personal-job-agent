# 安全整改记录 · 2026-09-19

范围：公共仓库工作区的五项整改，保留原有未提交改动。未发布远端、未重写 Git 历史、未更新已有桌面安装包。所有回归使用合成档案、临时数据库或模拟供应商，不发送个人资料或付费 API 请求。

## 1. 公共代码与运行时资料隔离

- 浏览器档案预览从需授权的 `/api/profile` 读取，通过 `textContent` 渲染；缺失项为中性占位。
- 浏览器任务、面试准备、联络文案从当前 Profile 的已确认事实生成，不补造院校级别、实习、奖项、指标或到岗承诺。
- 短信验证码不再注入云端模型任务；验证码、登录和最终提交仍交由本人处理。
- 指定的个人标识扫描在当前 `src/`、`tests/` 零匹配。扫描结果只记录结论，不复制敏感值。
- 输出、评测 JSON、本地 Chrome 启动脚本及调试日志已加入忽略规则；这些指定路径没有既有被跟踪文件。

## 2. 短信通信

- LAN GET 一律不提供验证码，OPTIONS 拒绝，无通配 CORS。
- 写入使用独立的私有 PSK，接受 `X-SMS-Token` 或配对 URL token；恒定时间比较，拒绝网页 Origin。
- 仅绑定指定端口；不再回退 8000。限制请求体与读取时间，响应及日志不回显短信或密钥。
- 配对 URL 和最新验证码只由本机操作 Token 鉴权的接口提供；外部网站、扩展 Origin 即使携带操作 Token 也被拒绝。
- **局限：LAN HTTP 不提供传输加密，不能防御同网段中间人。仅可信局域网使用，不公开配对链接。**

## 3. AI 配置

- 三处调用共享 `get_openai_client`，统一超时与零自动重试。
- OpenAI 缺省模型为用户指定的 `gpt-4o`，明确配置的模型不被覆盖；兼容端点需要模型和地址。
- 回归为模拟供应商验证，不代表任意账户均有该模型权限。

## 4. 岗位链接读取

- HTTP/HTTPS、无 URL 凭据、所有 DNS 答案必须为公网地址；覆盖 IPv4、IPv6、保留地址及已知 NAT64/6to4/Teredo 转换前缀。
- 连接固定到已验证的数字地址，HTTPS 保留原主机名证书校验，禁用系统代理路径；逐跳验证重定向。
- 响应体及跳转次数受限，绝对期限 watchdog 中断慢速读取，超时 EOF 不当作成功；读取失败、短页面、SPA/反爬提示均保留原输入且不继续调用 AI。
- DNS 超时结束请求等待，但无法取消操作系统底层正在进行的 DNS 解析线程。

## 5. 界面与交互

- 关闭按钮 44×44；设置新增复制 Agent Token，成功后不将 Token 渲染为文本。
- 短信查询串行轮询，收到验证码降为十秒间隔；弹窗关闭停止定时器并清空敏感显示。
- 使用 Impeccable 的边界与错误处理规则进行小范围加固，未重做现有视觉设计。
- 全量回归发现可选 Office COM 转换超时后持有 DOCX 文件锁。默认导出改走已有本地 PDF 渲染器，不再自动启动 Office；需要本机 Office 排版时可显式设置 `JOB_AGENT_USE_OFFICE_PDF=1`，该可选路径仍依赖 Office 状态，不作为默认验收路径。
