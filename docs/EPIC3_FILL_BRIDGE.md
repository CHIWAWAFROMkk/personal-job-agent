# 投递辅助

## 使用流程

1. 在扩展设置中填写本机工作台地址和配对密钥。只支持 localhost / 127.0.0.1，密钥不发送给招聘页面。
2. 在招聘页面打开插件，输入工作台岗位编号，先预览字段，再确认辅助填入。页面必须与岗位来源同主机，使用标准 HTTPS。
3. 返回招聘页面检查结果，上传已审阅简历，手工处理登录、验证码、筛选问题和最终提交。

## 安全与兼容边界

- 只使用当前用户已确认资料；最小字段集不包含家庭地址、政治面貌、密钥或本地附件路径。
- 普通字段采用静默写入，不派发 input/change 事件，也不点击提交。部分受控表单需要本人重新输入才能被网站识别；不能保证任意第三方页面没有自身副作用。
- 已有值、隐藏/只读字段、歧义标签、薪资/主观问题、文件上传与验证码不会自动填写。
- 短信同步、工作台验证码录入和扩展验证码接收已移除。验证码直接在招聘网页中填写。
- 扩展不是绕过网站风控的工具。
- 扩展弹窗打开时绑定当前用户资料；切换用户后，旧弹窗的写入返回 409。关闭并重开弹窗、核对当前资料后才能继续。外部 Agent 写入须先以 `X-Agent-Token` 读取 `GET /api/agent/state` 的 `profile_context`，并在写入请求中携带 `X-Profile-Context`；旧版客户端缺少此请求头也返回 409，不能自动重放旧写入。
