# 本机 HTTP 访问边界

本地优先不等于本机所有客户端可信。工作台拒绝明确的非同源 Origin、重复来源头及跨站 Fetch Metadata。普通网页不能通过跨站请求读取工作台或领取操作令牌；服务不启用通配 CORS。

伴侣扩展须由用户手动配对独立 Agent Token。有效 Token 的扩展例外仅适用于岗位收录、岗位代填资料、代填会话及明确的 Agent 只读接口；不能用于读取工作台首页、Dashboard、简历文件、设置或领取新令牌。UI Action Token 不授权扩展来源。

为保持本机 CLI 和桌面窗口兼容，不带浏览器来源头的本机请求仍然可用。本机制不是针对已控制本机的程序、能够隐藏来源的特权扩展或已窃取凭据的攻击者的隔离沙箱。Dashboard 仍是本机 UI 的令牌初始化入口，不能对外代理或暴露到局域网/公网。需要更强隔离时，应增加桌面启动会话认证，并保护所有敏感读取入口。

未授权 POST 最多丢弃 8 KB 请求体，读取超时 0.2 秒，既不解析也不执行，以避免 Windows 在返回 403 前因未读请求体重置连接。超大、畸形或慢速请求不完整读取。

验收覆盖在 `tests/test_http_origin_boundary.py`、`tests/test_sensitive_routes.py` 与 `tests/test_fill_bridge.py`；测试只使用隔离的合成档案。
