# 2026-09 求职工作台加固

在 v0.8.3 工作区已有的路由、脚本与提示词拆分基础上修复运行缺陷，保留本地优先、事实引用和人工最终提交的边界。本轮不是模型训练，也没有改变匹配评分标准。

## 用户可见行为

- 前端模块可完整加载，职位、资料和 Agent 对话恢复正常；个人资料的渲染与表单填充使用独立模块。
- 网络失败、异常 JSON 和超时给出明确提示。超时覆盖响应正文；写操作不会自动重试，避免重复生成或修改。
- 重叠刷新合并，操作结束后仍取得新数据；打开的连接设置不被后台刷新重置。
- 切换岗位后，先前岗位的项目运行结果不会覆盖当前岗位。
- 手机资料页不再横向溢出；职位详情指标为两列；弹窗关闭按钮保持 44px 可点击区域。

## 后端与数据

- JS 静态资源只从启动时建立的白名单中返回，拒绝目录穿越。
- GET/POST 等入口核验本机 Host 和端口；保留 Origin 和请求令牌校验。不支持的写请求返回 JSON 405。
- 未授权请求立即拒绝，不等待正文。重复长度头、分块传输、截断或超时正文得到明确错误。
- 内部异常写入本地日志，对客户端返回通用 JSON 错误。文件下载先成功读取再发 200。
- JSON、文本、二进制和画像写入共用同目录唯一临时文件，关闭后替换；Windows 短暂占用采用有界重试。失败保持原目标，清理自己创建的临时文件。
- 这只保证单次写入完整，不提供跨请求事务；多个成功写入仍以最后一次替换为准。

## 打包与回归

- Python 包和 Windows 打包脚本包含三个提示词文本资源。
- 固定合成评测和前端模块/请求测试已加入 CI 配置。CI 尚需推送后运行，本地执行记录另行保存。
- Python 测试：`.venv/Scripts/python.exe -m pytest -q`
- 前端测试：`node --experimental-vm-modules --test tests/test_frontend.mjs`
- 固定评测：`.venv/Scripts/python.exe evals/run_baseline.py`

验收使用合成数据；没有读取真实简历或调用付费模型。浏览器检查覆盖桌面/390px、今日到详情、本地 Agent 回复、资料和弹窗；这不等于所有页面和全部外部招聘网站验收。没有自动发布 GitHub 或替换已安装 EXE。
