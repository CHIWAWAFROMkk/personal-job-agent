# 操作与能力边界

- 操作按钮使用单行短标签、可见边框与清晰的主次和禁用状态。说明放在按钮外。
- 窄窗口任务区转单列，不通过裁切或缩小文字塞进操作按钮。
- 主要流程为选择岗位、生成草稿、人工审阅、打开招聘页及补录进度。
- Agent 辅助分析岗位、修改真实简历和准备面试；登录、填写、上传与最终提交由用户完成。
- 失效状态只作用于单个岗位，可以恢复，不屏蔽整家公司。
- 云端生成或润色失败时显示错误、保留原稿，不静默替换为本地简版。
- 公开版保留每位用户自己的求职方向与配置；不分发开发者的个人资料。

回归：`scripts/ui_controls_qa.py`、`scripts/company_ignore_qa.py`、
`scripts/resume_popup_qa.py` 使用隔离样例，不投递、不访问真实招聘网站。
