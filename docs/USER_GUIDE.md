# 个人求职 Agent 使用与恢复指南

## 第一次使用

完整解压桌面 ZIP 后，双击 `PersonalJobAgent.exe`。无需安装 Python，也无需先购买或配置 AI 服务。

1. 在首页导入自己的简历，填写姓名、目标岗位和城市。展开“更多资料”核对邮箱和电话；系统只识别抬头中无歧义的联系方式，有多个候选时需本人填写。确认原文真实后保存；照片、通勤和 API 可以稍后补充。
2. 添加一个岗位。可以粘贴完整 JD，也可以手动填写公司、岗位、地点。检查识别出的名称和招聘链接；无法读取网页时，直接复制岗位文字。
3. 选择“准备投递”。本地模式也能生成材料；完成后阅读当前 PDF，检查事实、排版和联系方式。嵌入预览不可用时，使用“单独打开 PDF”入口查看同一个版本。
4. 云端改写需要另外核对事实。修改过材料后必须重新审阅，旧版本的确认不能沿用。
5. 在招聘网站自行填写、上传和提交。没有招聘链接时可先批准材料，再补齐链接；批准或打开页面均不代表已经投递。
6. 只有实际提交后才在工作台记录“已投递”。后续补录真实反馈和面试安排。

关闭程序后重新打开，已保存的资料、岗位和进度仍保留。页面操作失败时先阅读提示，再选择重试；不要为了消除提示反复点击提交。

## 程序与数据分开保存

默认个人资料目录为 `%LOCALAPPDATA%\PersonalJobAgent`。可将这段路径粘贴进资源管理器地址栏打开。若使用自定义 `--data-dir`，以该目录为准。

- `data/private`：个人档案、原始简历、API 设置、岗位库、操作记录和自动备份。
- `data/output`：生成的简历和投递材料。
- `logs/desktop.log`：桌面启动和诊断日志。

整份数据目录可能包含简历、联系方式和 API Key。仅备份到自己控制的位置，不放入公开仓库或作为问题附件发送。排障时优先提供版本号、操作步骤和界面错误；日志也需要先检查并遮去私人内容。

## 备份、升级、回退与换电脑

备份前保存操作并关闭所有使用这份数据的程序。然后复制整个资料目录到新的带日期文件夹，保留原目录；不要只复制 SQLite 主文件，因为尚未合并的数据可能仍在旁边的 WAL 文件中。

升级采用并排安装：将新 ZIP 解压到新文件夹，保留旧版本，确认备份后启动新 EXE。不要把新文件覆盖进旧程序目录。校验发行页提供的 SHA256 后再使用包内文件；在测试目录通过验收后再调整自己的快捷方式。

需要回退时先关闭程序，保留当前数据的副本，再启动旧版本。若升级涉及资料格式变更，不要直接让旧版本读升级后的资料；将升级前的备份复制到另一目录，并显式用 `--data-dir` 指向该副本。程序文件回退与数据回退是两件事。

换电脑时先关闭旧电脑上的程序，将完整资料备份复制到新电脑的默认资料目录或专门目录。首次启动后核对姓名、岗位数、最近生成的 PDF 与投递记录，再继续使用。

卸载程序只需在关闭后移除程序文件夹和快捷方式；个人资料不会自动移除。确认备份后，再自行决定是否删除个人资料目录。

## 切换用户中断或文件损坏

程序为用户切换保留持久化恢复记录，并以数据库事务提交标记判断切换是否完成。重新启动时，未提交的切换恢复旧资料，已提交的切换保留新资料；中断时的新文件保存在恢复归档中，避免覆盖原资料。

若恢复记录不完整、备份缺失或路径异常，程序会阻止继续混用资料并提示错误。此时保留整个数据目录和日志，先备份，再按实际情况恢复一份完整备份。不要删除恢复标记、单独拼接旧数据库与新 Profile，或在损坏档案上反复建档。

损坏的个人档案、API 配置或数据库不会自动被空白默认文件替换。应从同一备份恢复匹配的数据，或在新的资料目录重新建档，保留旧目录以便排查。

## API 与网络问题

- 未配置 AI：继续用本地模式，手动导入 JD。AI、搜索、地图是独立的可选服务。
- 官方 OpenAI / DeepSeek 明确返回认证失败 401：检查服务地址与 Key 是否匹配，更新 Key 后重试。该次本机预留会释放。
- 超时或结果不明：可能已经到达服务商，保留本机预留。先查服务商控制台，不要把修改上限或删除记录当成退款。
- 达到本机月度上限：停止云端调用或在了解实际账单后调整自己的限额。软件显示的本机剩余量不等于服务商余额。
- 地图或岗位链接不可用：保留已填写内容，改为手动输入地点、通勤时间或 JD，不需要重新建档。

## 窗口无法打开

确认 ZIP 已完整解压，EXE 与 `_internal` 文件夹位于同一目录；检查启动日志。桌面窗口使用 Microsoft Edge WebView2 Runtime，缺失时需安装或修复该组件。不要关闭安全软件或删除个人资料来尝试解决窗口故障。

标准投递辅助通过系统默认浏览器打开招聘页，不要求下载额外 Chromium。`Install-Optional-Browser.cmd` 用于可选的浏览器测试/命令行辅助功能，普通桌面流程可以跳过。

实站 AI 自动代填继续暂停。验证码、筛选题、简历上传和最终提交均由本人处理。工具提供可核对的材料和进度记录，不保证招聘结果。
