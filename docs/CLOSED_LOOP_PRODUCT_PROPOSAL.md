# 个人求职 Agent - 全流程闭环产品功能缺口诊断与工程实施方案

> **方案定位**：本方案旨在解决当前系统与真实个人求职需求之间的最后里程碑差距，将原本局部的“单点功能辅助”升级为覆盖**「全网捕获 → 精准匹配 → 双屏改写 → 无感代填 → 动态跟进 → 面试应答」**的 100% 端到端求职闭环。
> 
> 本文档已按照模块化工程任务包（Epic 1 ~ 5）标准编写，结构严密、边界清晰，可以直接交给 GPT 逐项执行落地。

## 二、 五大核心升级方案（闭环建设）

### Epic 1：全渠道岗位秒级捕获与时效守护 (Sourcing & Liveness Guard)

#### 1.1 现状痛点
用户在 Boss 直聘、小红书、大厂官网看到岗位时，必须手动复制整段 JD、公司、城市粘贴回工作台，操作断层；且许多实习或校招 HC 招满后链接失效，系统不知情。

#### 1.2 落地方案
1. **Chrome/Edge 伴侣轻扩展（无感吸纳）**：
   - 监听 Boss 直聘、牛客、国聘网、实习僧及常见大厂 ATS（如北森、Moka、飞书招聘页面）。
   - 在招聘页右下角悬浮半透明 Gemini 极光胶囊按钮：`[ ✦ 录入当前岗位到 Agent ]`。
   - 点击时自动抓取：公司名、岗位名、薪资、城市、原始 JD 正文、招聘链接、HR 活跃度，通过本机 HTTP API（`POST /api/jobs/import-fast`）秒级入库，并自动触发本地规则匹配。
2. **时效性与“虚假/KPI 岗位”避坑提示**：
   - 入库时自动检测“HR 最后在线时间”、“发布时间跨度”。若岗位常年挂着（超过 60 天仍未招满），标记“⚠️ 疑似 KPI 岗位/常青挂招”，在界面提示“建议谨慎投入精力”。

---

### Epic 2：双向画布简历精修与 ATS 穿透 (Interactive Split-Canvas Tailoring)

#### 2.1 现状痛点
当前生成简历只能一次性打成 PDF 下载，用户如果想局部改动一两句话，必须手动修改后台 JSON 或重新生成，没有所见即所得的精细调整界面。

#### 2.2 落地方案
1. **三分屏交互式工作台**：
   - **左屏（JD 与高频词清单）**：高亮提取该岗位的核心关键词（如 `数据清洗`、`SQL 复杂查询`、`HR 组织架构`、`转化漏斗`）。
   - **中屏（实时富文本简历画布）**：直接以 A4 纸张比例呈现简历排版，支持点击任意文字即时微调，实时显示“当前 ATS 关键词穿透率（Match Density: 88%）”。
   - **右屏（Gemini 浮岛 Copilot）**：针对光标所在的经历，提供 3 种 STAR 改写建议（如：“增强量化数据”、“突出组织协调”、“强调技术工具”），一键点击即替换对应段落。
2. **多赛道简历底稿库 (Track-based Profiles)**：
   - 支持管理 3 套真实经历侧重点：`运营策略版`、`数据分析版`、`HR/综合管理版`。
   - 匹配到不同通道职位时，自动选用最合适的底稿作为起点，杜绝“千岗一版”或经历错配。

---

### Epic 3：双模式可靠代填与多维验证码后备 (Zero-Friction Auto-Fill)

#### 3.1 现状痛点
1. 很多大型招聘网站（如腾讯、字节、智联）对 Playwright/CDP 自动化注入有严格检测，容易触发风控滑块。
2. iPhone 快捷指令短信同步虽然精巧，但在不同网络环境或用户不熟悉 iOS 快捷指令配置时容易卡壳。

#### 3.2 落地方案
1. **“伴侣扩展原生代填模式”（抗风控主力方案）**：
   - 用户使用自己平时使用的日常浏览器打开招聘官网（自带登录态、无需重新过 Cookie）。
   - 伴侣扩展识别页面上的 `<input>`、`<select>`、附件上传框，将 Agent 本地存储的已核实档案一键高亮预览并填入，**避免 CDP 自动化特征被反作弊系统识别**。
2. **极简多维验证码输入后备**：
   - **方案 A（短信自动同步）**：保留现有的 iPhone Webhook 机制。
   - **方案 B（屏幕 OCR 截图秒录）**：提供 Windows 快捷键 `Alt + V`，直接截取手机投屏窗口或微信传输助手中的验证码图片，本地 OCR 毫秒级提取 4~6 位数字并填入。
   - **方案 C（工作台数字软键盘）**：在 Web 工作台浮层常驻一个大按钮数字手输框，按回车直接填入网页，无需在手机与电脑间反复核对。

---

### Epic 4：动态消息解析与求职漏斗日程 (Tracking & OA Calendar)

#### 4.1 现状痛点
投递完之后，后续的笔试测评 (OA)、HR 微信沟通、面试通知散落各处，用户经常忘记截止日期，投递转化漏斗缺乏数据支撑。

#### 4.2 落地方案
1. **求职通信消息嗅探与解析**：
   - 本地提供快速文本录入框或支持本地读取授权邮箱（IMAP 本地无上传）：
   - 粘贴短信或邮件正文（如：“【美团】何彦钧同学，请于 9月22日 20:00 前完成在线综合素质测评...”）。
   - AI 自动提取：**公司名、任务类型（在线测评/一面/HR面）、截止时间、测评链接**。
2. **求职看板与日程日历 (Kanban & Calendar)**：
   - 自动将岗位流转为：`已投递` → `待测评(OA)` → `待面试` → `已发Offer` → `已婉拒/挂掉`。
   - 顶部提供紧急倒计时栏：`距美团在线笔试截止还剩 18 小时`，支持一键生成 `.ics` 日历文件导入 Windows 日历或 Outlook。
3. **投递有效性归因诊断**：
   - 每周汇总数据看板：`本周投递 12 家，已读率 66%，测评通知 3 家，面试 1 家`。
   - AI 针对未通过的岗位给出原因复盘（如：“这类岗位 90% 优先理工科，建议下周调高 HR 数字化赛道权重”）。

---

### Epic 5：真实面试对练模拟器与实战防御 (Mock Interview & Realtime Aid)

#### 5.1 现状痛点
当前面试准备只有静态文本建议，用户缺乏实战临场感；面试过程中被问到简历空白期或非对口专业时容易紧张语塞。

#### 5.2 落地方案
1. **沉浸式 AI 模拟面试官 (Mock Interview Room)**：
   - 结合目标岗位 JD 与个人简历，启动全真模拟面试。
   - 针对个人背景短板（如专业跨度、实习成果量化依据）进行**连续三轮追问**（压力面），并在结束后出具《面试表现评分卡》与建议应答话术。
2. **实战桌面悬浮提示卡 (Compact Floating Teleprompter)**：
   - 面试进行时，开启极简桌面置顶微型悬浮窗（不遮挡腾讯会议/飞书）。
   - 输入或语音识别面试官问题，右侧毫秒级显示 3 点核心提纲（STAR 框架：情境、行动关键词、量化成果数字），让用户答题逻辑清晰、数据精准。

> **使用方法**：你可以将以下方框内的 Prompt 原封不动发送给 GPT，让其分阶段执行编码开发。

```markdown

你是一位资深全栈系统架构师与前端体验专家。请基于本地求职助手项目（基于 Python 3.13 + 本地 SQLite + 原生 JavaScript / CSS 现代 Web 架构，且已全面应用 Google Gemini 极光设计语言），为项目分步实施以下五大闭环功能模块。

### 核心约束

3. 严格遵循触控目标 >= 44x44px 与无障碍 (a11y) 规范。

### 第一阶段任务：交互式双屏简历精修工作台 (Epic 2 优先)
请编写前后端代码与对应单元测试：
1. 后端新增 `/api/resume/tailor-live` 接口：接收岗位 JD 与经历段落，返回保留真实依据的 3 种定向优化建议，并计算与 JD 的核心关键词覆盖度。
2. 前端重构职位详情中的简历审阅区域，呈现双屏实时编辑体验：
   - 左侧：JD 硬门槛与核心能力词云。
   - 中间：交互式 A4 画布，点击段落可直接修改，实时计算 ATS 匹配分。
   - 右侧：Gemini 胶囊面板提供一键润色建议。
3. 提供对应的全量自动化测试文件，确保通过率 100%。
```

## 四、 实施路径建议与交付排期

1. **第一步（核心突破 - 预计耗时 1~2 天）**：
   - 落地 **Epic 2（双屏简历精修）**：让每一份投递材料不仅“快”，而且“准”，极大提升简历初筛通过率。
2. **第二步（可靠性增强 - 预计耗时 1 天）**：
   - 落地 **Epic 3（伴侣扩展代填模式 + 屏幕 OCR 极简验证码后备）**：彻底解决官网反自动化与手机短信不同步的痛点。
3. **第三步（全景掌控 - 预计耗时 1 天）**：
   - 落地 **Epic 4（测评日程管理与投递看板）**：让投递后的进度清清楚楚，不错过任何一场笔试测评。
4. **第四步（致胜一击 - 预计耗时 1~2 天）**：
   - 落地 **Epic 5（AI 模拟面试官对练与复盘）**：把拿到的面试机会稳稳转化为最终 Offer。
