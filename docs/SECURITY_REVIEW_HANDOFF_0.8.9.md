这是 2026-09-24 的本地候选版，针对 0.8.8 独立评审确认的 2 项 P1 和 7 项 P2。源码包、桌面包与实际安装状态必须分别核验；本文件不是安全认证。请使用合成资料和模拟服务商响应复核，不要把真实简历、密钥、岗位库或浏览器会话复制给审查者。

## 当前产品边界

实站 AI 自动代填从界面和本地接口暂停；“投递字段预览”只使用本机资料生成模拟计划，不打开网页，也不调用云端 AI。原因是第三方网站可能在输入或上传时自行提交，限制点击提交按钮不足以保证用户控制。标准投递流程仍由本人在招聘网站核对、填写、上传与提交。

本机用量不是服务商账单。响应不明的调用可能收费，也可能未收费；预留保守占额，需根据服务商后台核账。切换用户保留 Profile、SQLite 和旧产物备份供故障恢复；API 密钥配置、用量记录与本地 Agent 令牌仍属于当前 Windows 账户，切换应用内用户不会重置它们。同一 Windows 用户权限下的恶意本机进程可访问本地服务。切换期间的请求隔离覆盖当前桌面服务，不能约束另一个桌面进程或 CLI；不要同时在两个进程中操作同一份用户数据。

Dream-RSI 仍只收录固定版本的研究资料与接入评估，未运行第三方实现，也未启用自我修改。源码包不得附带个人数据目录、API Key、浏览器登录状态或旧私有 Git 历史。

建议独立审查先从 0.8.8 报告附带的复现场景回归，再检查所有云端调用的准入、响应结算与超时路径，以及新建、润色、批准和下载简历的事实与哈希边界。桌面可执行程序要单独在隔离资料目录验收，不能以源码测试代替。
