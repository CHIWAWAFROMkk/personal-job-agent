# 功能简化与新人引导

本次修改形成 v0.8.6 本地候选版，基于此前的 v0.8.5 新人引导版继续简化操作与改善大量岗位的处理。Windows 包已生成并在隔离合成数据中验证；工作机已保留旧目录、备份原快捷方式，并将快捷方式指向新版本，仍沿用原数据目录。尚未推送远端或发布公开下载版本。

## 行为变化

- 移除短信服务模块、自动监听、所有短信路由、手动验证码中转以及扩展验证码轮询。旧接口不再提供服务，不删除用户历史配置或数据。
- 首页按真实状态展示建立资料、添加岗位、准备简历。首次建档保存后返回首页继续添加岗位，刷新保留实际资料状态；没有任务时不展示空反馈区。
- 使用指南从任何首页状态都能定位到当前步骤；资料不完整时提示修复，无可提取事实的简历不会被保存成已完成档案。
- 网页岗位提取失败不再显示成功；自动带回原职位链接，未识别的公司或岗位名称需人工填写，服务端也拒绝保存占位值。
- 没有形成匹配结论的岗位只显示“核对岗位”，不冒充算法推荐；导入与资料保存的错误直接显示在当前表单。
- 删除首页四个竞争快捷入口和浮动对话输入；收起重复设置入口。建档优先显示简历、目标岗位、地点与求职类型，其余资料可展开补充。
- 岗位主要操作保留准备材料与打开招聘页；代填、招呼语和面试收进更多工具。验证码及最终提交仍由用户直接在招聘网站完成。
- Dream-RSI 只作固定版本研究资料收录，未安装、执行或集成第三方实现。
- 工作台一次读取全部岗位，不再截断于 1000 条；批量匹配写入和材料目录索引避免逐条重复扫描。职位列表每页展示 60 条，搜索和筛选覆盖全部岗位，并在翻页后同步更新详情。
- 进度页直接提供候选链接逐条核验入口，支持按核验状态筛选、翻页、打开来源、记录核验结果，以及将线索带入正式岗位录入表单；必须补齐公司和完整岗位说明才可保存。
- 资料表单可清空已回填的求职偏好；联系方式和其他备注需成功读取旧值后才会同步清空。切换新用户时清空旧资料输入，避免把上一位用户的联系方式带入新档案。
- 投递状态必须显式选择；保存成功后若页面刷新失败，会明确提示已保存，避免重复提交。

## 验证

- Python 全量：441 passed。
- Node 前端与扩展：30 passed。
- 旧并发审阅测试曾漏报线程异常；现明确断言过期简历审阅返回 409 且不生成批准文件，线程异常转交主线程。修正后单项 `-W error` 通过，服务逻辑未改动。
- `scripts/simplification_qa.py`：实际通过界面建立合成档案、导入岗位；验证刷新后状态保持、首次使用时“使用指南”可定位、岗位提取失败与占位值处理、12 个阶段/尺寸/主题组合、无页面错误、无横向溢出、无短信请求。截图与报告在 `build/simplification-qa/`。
- 合成 1200 条岗位：工作台快照完整返回 1200 条，连续两次约 0.18 秒；浏览器首次进入并显示 60 条当前页约 0.62 秒。该数字是当前工作机、合成档案与示例岗位的实测，不代表所有真实数据库和机器的上限。
- `scripts/high_volume_ui_qa.py`：125 条正式岗位和 45 条候选的真实浏览器流程，验证列表 60/60/5 翻页、筛选与详情一致、跨页搜索、候选逐条核验/翻页/导入，以及 390px 布局无横向溢出。
- `security_ui_qa.py` 与 `fill_bridge_qa.py`：桌面/窄屏资料预览、配对、普通会话及关闭检查通过。
- `extension_fill_qa.py`：合成网页上的姓名和电话预填正常，不覆盖已有或歧义字段，不填写验证码、不触发表单提交。
- 新版 EXE 在隔离合成资料目录中启动并通过首页、材料准备、自动打开审阅、PDF 版本绑定、旧版本冲突拒绝、无短信请求等打包验收；源码和安装包主界面脚本 SHA256 一致。

所有验收使用合成资料，没有真实投递、付费模型调用或用户数据迁移。旧安装目录与原快捷方式的日期备份保留，以便回退。未用真实用户数据实测操作系统浏览器、资源管理器或 PDF 查看器联动。

旧的本地 `product_trial.py` 使用已过时的 create-resume / approve-resume 按钮选择器，整条脚本未通过，不能据此宣称最新两步准备流程端到端通过；本次的新用户验收已迁入上述独立脚本。

## 尚待验证和改进

- 实际招聘网站的岗位导入质量、外部浏览器/PDF 查看器联动、最终人工投递及状态回传未在真实用户账号下端到端验收。
- 当前大量岗位验收覆盖到 1200 条正式岗位和 45 条候选的界面操作；更大数据集、批量导入和长期运行的性能尚未测定。
- 辅助工具仍多，虽然已折叠与分层，需继续以真实新用户观察来检验是否足够易用。
- `scripts/deploy-desktop.ps1` 仍固定于此前已核验的 0.8.5 发布包；本次 0.8.6 本地候选版使用 `scripts/build-desktop.ps1` 和隔离打包验收，不应使用旧部署脚本代替其发布验证。
