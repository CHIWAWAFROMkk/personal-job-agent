# 0.8.5 实测与生产差距

日期：2026-09-20。本文区分实际验证、代码检查与未完成事项，不用未经定义的百分比表示完成度。

## 本轮实际修复

- 接回简历精修、通知登记/日历、模拟面试与手动验证码四个前端模块。
- 修复进度/资料被背景遮挡、手机进度文字挤压、无效语音入口。
- 缺档案先引导建档，失败导入不会留下半成功岗位。
- 照片可选；从原文导入的未分类经历保持“其他经历”，机构未知明确标注待完善，不编造名称。
- 代填预览改为读取已确认档案，不再以默认成绩、学历、事实数代替用户数据。
- 不以任务返回等同于代填成功，不承诺绕过风控或验证码自动成功。
- HTTP JSON 响应包含准确长度；正常取消页面请求不会记录为内部故障。
- 浏览器请求统一检查明确的 Origin 与 Fetch Metadata，配对扩展限定端点；详细威胁模型见 `SECURITY.md`。
- 代填弹窗的异步结果绑定当前打开批次，旧岗位响应不能覆盖新岗位执行按钮。

## 可复现验收

所有测试使用独立合成资料，不操作真实求职数据、不调用付费模型、不提交招聘申请。

- 干净公开发布副本 Python 全量测试：388 项通过；包含拒绝请求的有界处理与独立临时档案测试。
- Node 前端及扩展逻辑：22 项通过。
- 固定离线基准：15 / 15 通过。
- `scripts/product_trial.py`：支持源码与 `--exe`；空用户建档、录入、生成草稿、编辑、PDF 预览、合成审阅/材料包持久化、进度入口均通过。
- `resume_tailor_qa.py`、`tracking_qa.py`、`mock_interview_qa.py`、`fill_bridge_qa.py`：桌面/窄屏、Aurora/Cosmic 通过。
- `security_ui_qa.py`：本地档案预览、敏感信息不再用假占位、配对复制与关闭清理通过。
- `browser_dialog_race_qa.py`：慢档案请求可立即关闭、旧档案/环境请求不覆盖新岗位、模拟执行只作用于当前岗位。
- 人工检查合成单页 PDF：中文可读，无裁切或重叠；资料缺失仍需本人补充，不能因此宣称简历已可投递。

## 对外部审计摘要的核查

| 摘要说法 | 当前证据与判断 |
| --- | --- |
| 无 CI/CD | 已有 Windows CI；缺自动打包发布 CD。公开快照曾遗漏 CI 使用的离线基准脚本，本轮补入，并运行全部 Node 测试而不只单个文件。远端 CI 成功必须单独核验。 |
| 新用户没有引导 | 已有可行动的建档/目标引导，实际 EXE 建档通过；仍不是连续分步向导。 |
| 所有 AI 零重试、15 秒超时 | 不准确：公共工厂为 15 秒/不重试；部分模块单独建客户端使用 SDK 默认值。真正问题是策略分散、不一致。 |
| 只支持实习僧 | 网站自动反馈采集器目前只有实习僧；跨平台通知粘贴解析与手动状态登记可用。 |
| 投递必需六步 | 不是固定六步状态机；有重复确认，但 PDF 事实审阅与网站最终人工提交不能省掉。 |
| 任意扩展凭 Origin 读取档案 | 显式扩展 Origin 的敏感档案接口仍检查 token/来源。真正风险是本地页面读取边界及具备 localhost 权限的扩展，需统一防护与明确威胁模型。 |
| 没有 TODO 即质量高 | 不成立。可运行流程、失败恢复、安全边界和输出检查才是验收证据。 |

AI 重试策略不能简单全局开启：失败请求也可能消耗额度，应设有限退避并计入 SDK 自带重试，参见 [OpenAI 官方速率限制说明](https://developers.openai.com/api/docs/guides/rate-limits)。本轮没有擅自更改用户的模型、调用外部 AI 或扩张重试计费。

## 仍需实施或真实验证

1. **安全边界**：本机服务不是多用户或恶意本机程序的安全沙箱。Origin/Fetch Metadata 防护不能代替完整私有会话机制，也不能保证抵御高权限浏览器扩展。本轮最小防护不等于完成该架构升级。
2. **桌面内岗位发现**：搜索仍依赖命令行/外部助手；应增加可取消任务、进度、失败恢复、来源与时效核验，并保持渠道限制。
3. **AI 网络策略**：统一 Provider 客户端与调用预算，按错误分类重试；认证错误不能重试，超时可能已经产生费用，不能盲目重复写入或承诺零费用。
4. **业务用例层**：先提取一条关键路径并用 CLI/API 等价测试证明，再逐步减少重复；不在修复阶段一次性重写所有模块。
5. **数据迁移与恢复**：建立版本化迁移、升级备份和回退验收；目前手工列检查不等于没有兼容措施，但缺少完整机制。
6. **更多渠道进度**：仅在平台允许且可靠时增加；登录、验证码、测评与最终提交仍由本人处理。
7. **真实服务验收**：用户配置的 AI、实际招聘网站、干净 Windows 设备及 macOS 尚不能由本机合成测试代替。

当前定位是可测试、可本地使用的候选版本，不是“100% 自动求职”或已经在所有电脑/招聘网站验证过的成品。
