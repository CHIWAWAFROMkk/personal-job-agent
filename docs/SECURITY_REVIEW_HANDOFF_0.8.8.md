# Personal Job Agent 0.8.8 源码复核交接

这是 2026-09-23 的本地候选版。源码与桌面包需分别核验；本文件不是安全认证。请勿把真实简历、个人资料、API Key、岗位库或浏览器登录状态加入源码包。0.8.6 第一轮评审和 0.8.7 的处理记录分别见原评审文档与 `SECURITY_REVIEW_HANDOFF_0.8.7.md`。

## 本轮重点

- 云端 AI、搜索和地图调用逐入口检查本机月度上限，并在同一进程内为执行中的请求预留名额；失败释放，成功结算。已有用量文件若损坏或不可读，暂停新云端调用，避免误把未知用量归零。用量仍不等于服务商账户余额。
- 付费面试准备从 GET 改成需要工作台 action token 的 POST，防止读取或刷新意外触发费用。
- 实验性的 browser-use 智能体每次任务可能发起多次模型请求，当前无法逐次核算。设有 AI 月度上限时拒绝运行任务；未设置上限时提示该入口不进入本机成功请求计数。
- 工作台短时缓存大规模快照，数据库、资料变化和页面写操作会刷新；跨进程材料文件改动最多有 10 秒延迟。保留所有岗位行，不用静默截断掩盖性能问题。
- 移除非实习岗位上无意义的日薪全文扫描；桌面验收实现从常用启动模块惰性分离；前端未处理错误显示安全恢复提示，日程使用设备本地时区。

## 安全边界与仍需复核

1. 本地月度上限的并发预留仅在一个进程内严格；CLI 与桌面进程同时使用同一用量文件尚无跨进程事务。真实消费和余额以服务商后台为准。
2. `/api/dashboard` 返回的 action token 防护跨站网页；同一用户权限下的恶意本机进程可以访问本地服务，该威胁不因把 token 改放 HTML 而消失。
3. 浏览器代填仍属实验功能。它不应代用户完成最终提交、验证码或条款确认；对真实招聘网站和付费服务的端到端副作用尚未在此候选版验证。
4. 万级岗位冷启动仍需全量本地匹配和策略计算。规模脚本使用合成数据，不能替代真实长时间运行与跨机器性能测试。
5. Dream-RSI 仅收录固定版本研究材料与接入评估，未执行第三方代码，未启用自我修改或自我部署。

独立复核请从额度文件损坏、多线程同时请求、请求途中失败、供应商返回本地回退、浏览器辅助任务、跨时区日程与桌面验收隔离这些路径入手。报告应附可复现输入、实际结果及精确源码位置。
