## 结果

- 官方招聘链接：浏览器返回 ERR_CONNECTION_CLOSED，无法确认岗位仍然开放；这不是岗位已下架的证据。Chrome 控制入口本次不可用，改用应用内浏览器也未成功加载。
- 本地 HTTP 工作台读取：200。
- 实际岗位专属简历草稿生成接口：200，成功输出一页带照片 PDF。
- PDF 已渲染检查：无明显页面溢出，但英文字符间距异常；渲染器报告 STSong-Light 字体替代。该模板使用未嵌入的 CID 字体，跨电脑显示需修复和重新验收。
- 内容质量：个人优势与自我评价重复，本地生成成功不等于达到定向投递质量。
- 评分一致性：保存分数 100，使用当前档案和规则重新计算 95；生成路径优先复用历史匹配，未看到档案变更后的失效校验。差值本身不证明某个分数错误，界面需说明计算时间及档案/规则版本。

## 修复优先级

### 本地修复复验

- PDF 改为嵌入本机中文 TrueType 字体，不再依赖阅读器替换 STSong-Light；不在仓库分发系统字体。缺少字体时明确报错，可通过 JOB_AGENT_PDF_FONT 指定本机字体。Windows 实际生成已验证 FontFile2 嵌入；其他操作系统尚未真机验收。
- 同一真实岗位在隔离数据副本重新生成成功，一页带照片，英文单词和项目符号显示正常。
- 新生成草稿不再自动重复填充“自我评价”；用户自行填写的该字段仍保留。
- 生成材料时重新进行本地匹配，只有语义结果变化才追加记录；测试副本分数由 100 更新至 95，与当前计算一致，投递状态保持不变。此修复不意味着所有列表在档案编辑后会立即批量重算。
- 原个人数据、安装包和远端仓库未改动。
- 修复后全量 Python 回归：250 项通过（67.94 秒）。新增测试覆盖字体嵌入、英文文本提取、档案变化后的重算、相同结果不重复追加和投递状态不变。

### 简历内容选材复验

- 本地选材不再按关键词零命中删除整段已确认经历；最多五段、十条事实，每段预留至少一条，段内重复事实去重。超过预算的经历 ID 和选材规则写入私有草稿 selection；不代表所有经历无条件全部展示。
- 生成草稿中的经历 ID 受保护：云端遗漏时恢复原稿，超过五段/十二条预算则拒绝该云端结果并沿用本地回退。未通过真实供应商调用验证，使用模拟返回覆盖恢复路径。
- 摘要改用已确认行动与产出，不再堆砌学校和公司名单；局部标签体现数据处理、内容运营等任务，不再全部叫“业绩”。不补造 STAR 结果。
- 同一真实岗位通过实际本地生成接口重新输出，恢复了原先未选入的课程项目；渲染为一页带照片 PDF，目视未见溢出。未动原数据库、未批准投递、未发布。
