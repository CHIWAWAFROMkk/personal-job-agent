# 1.0.0rc1 独立复核交接

基线为 0.8.11 源码审查包。本候选版本保留人工事实核对、当前 PDF 审阅和本人最终提交边界；实站自动代填继续暂停。运行测试须使用隔离合成资料，不读取个人资料或调用付费接口。

## 主要变化与复核入口

- `profile_recovery.py`、`profile_onboarding.py`、`job_repository.py`、`desktop.py`：持久用户切换记录与 SQLite 提交标记；未提交回滚、已提交保留、恢复再次中断可重试。无法确认时阻断 Profile 和 HTTP 数据读写。
- `portable_resume.py`、`resume_editor.py`、`resume_polish.py`、`resume_reference_layout.py`、`resume_compose.py`：原文导入使用未结构化经历，不编造机构或在读状态；仅去除可证明重复的纯字段，保留混合资格和经历。空摘要不产生空白事实对照行，但仍要求有效经历、已确认来源和人工核对。
- `profile_onboarding.py`：识别原文抬头唯一邮箱/中国手机号；明确输入优先、已有资料显式清空继续生效；多个候选和第三方信息不猜测。
- `local_matcher.py`、`jobs_api.py`：同行 JD 标签边界；无显式信息时不把整段说明误作公司或岗位名称。
- `dashboard.html`、`main.js`、`review-dialog.js`：键盘焦点、当前 PDF 独立入口、缺招聘链接时的准确文案与联系方式核对提示。
- `desktop_qa.py`、`verify_packaged_desktop.py`：原生窗口两进程验收，必需步骤缺失或跳过必须失败。
- `package_source.py`、`privacy_audit.py`、构建与部署脚本：版本动态读取、按当前 ZIP/EXE 哈希绑定部署、隐藏目录排除与嵌套私有配置阻断。

## 本轮发现并修复

用户切换进程中断造成新 Profile 与旧岗位混用；原生验收可跳过核心步骤仍成功；导入姓名误作经历、重复摘要及内部占位进入简历；唯一联系方式未进入 Profile/PDF；过宽元数据过滤删除混合资格原文；源码收集包含审计忽略目录；桌面资源携带含开发路径的 Python 缓存。上述问题均有隔离复现或对应回归。桌面验收调用退出后还原其覆盖的环境变量，避免污染同进程后续操作。

## 验证方法

按 `RELEASE_CHECKLIST.md` 执行全量测试、真实首次使用、PDF 逐页渲染、切换与恢复中断、完整备份恢复、实际 ZIP 解压出的 EXE 两进程原生验收、并发审批及部署演练。源码、桌面文件及 ZIP 分别执行隐私审计；核对冻结模块与前端资源一致性。

具体发行结果与包哈希由本次发行验收报告给出。文件哈希用于确认交付一致性，不代表数字签名或安全认证。

## 仍需区分的边界

合成数据通过不等于真实陌生用户试用或招聘效果验证。原生 WebView DOM 与 PDF 字节检查不等于系统外部 PDF 阅读器、招聘网站或全流程视觉人工验收。物理断电、硬件损坏、任意外部程序并发写入，以及旧版本无恢复记录的事故，不在本次恢复保证内。保留完整数据备份与旧程序后再升级。
