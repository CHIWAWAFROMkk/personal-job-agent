# Job Agent fonts

`NotoSerifSC-Variable.subset.woff2` and `NotoSansSC-Variable.subset.woff2` are
local, variable-weight web subsets of Noto Serif SC and Noto Sans SC. They
include Basic Latin, CJK punctuation, the full CJK Unified Ideographs block,
and full-width forms so the editorial interface does not depend on fonts
installed on the host machine.

- Use: Noto Serif SC for editorial display and measurements; Noto Sans SC for UI copy and controls.
