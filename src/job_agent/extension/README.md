# 求职 Agent · 岗位一键收录浏览器扩展（Chrome / Edge）

## 为什么需要这个扩展？
- **浏览当前页面**：在自己的浏览器中打开岗位，使用时仍需遵守招聘网站规则。
- **辅助收录**：从当前页面提取职位信息；解析结果、招聘有效期需自行核实。
- **同步到本地**：将识别结果发送到本地求职 Agent，实际结果以工作台记录为准。

---

## 30 秒安装教程（免打包、开箱即用）

1. 打开 Chrome 或 Edge 浏览器，在地址栏输入：
   - Chrome 用户：`chrome://extensions/`
   - Edge 用户：`edge://extensions/`
2. 打开页面右上角的 **「开发者模式」** 开关。
3. 点击左上角出现的 **「加载已解压的扩展程序」** 按钮。
4. 在文件选择框中，选中当前项目目录下的这个文件夹：
   `src/job_agent/extension`（相对于你下载的项目目录）
5. 安装完成！将扩展图标图钉📌固定在浏览器工具栏。

---

## 使用方法

1. 启动你的求职 Agent 工作台（默认运行在 `http://127.0.0.1:8787`）。
   在工作台设置中复制 Agent Token，填入扩展设置的对应字段；本地地址应与实际工作台地址一致。不要分享 Token 或包含它的截图。
2. 在浏览器中打开任意 Boss直聘/牛客等岗位详情页。
3. 点击右上角扩展图标，插件会自动识别岗位名、公司和 JD 内容。
4. 展开 **「收录当前岗位」**，点击 **「收录到工作台」**。请核实识别结果，实际结果以工作台记录为准。

## 辅助填写（1.1）

1. 在招聘网页打开申请表，点击扩展图标，输入工作台的岗位编号。
2. 点击「读取档案」，检查待发出的姓名、联系方式、教育与经历概要。
3. 确认目标网站正确后点「确认预填当前页」。已有内容不覆盖；多段教育/经历产生歧义时跳过。
4. 本人核对表单、手动选择附件和最终提交。扩展不上传文件、不点击网页按钮。

预填仅接受标准 HTTPS 页面，且当前主机名必须与已保存的岗位链接一致。官网跳转到不同域名的 ATS 时，请先核实目标，并在工作台更新岗位链接。不会因为同属一个品牌就自动信任跨域页面。

仅支持有明确 label / aria-label / autocomplete 的普通文本字段。下拉框、分组教育经历、Shadow DOM、iframe、自定义编辑器、薪资、地点、主观筛选题等需要手动处理。工作经历汇总只能填入明确标为「经历概述/经历汇总」的总览文本框，不会塞入单段工作描述。

**边界：**预填仅使用原生 value setter，不派发 input/change、键盘事件或点击动作，避免触发常见自动提交处理器。React/Vue 受控表单可能未采纳静默值，需要本人手动重输并检查。网页仍可能通过自定义轮询读取字段，不把本功能视为任意网页上的绝对禁止提交沙箱。尚未宣称所有北森/Moka/飞书版本真机验证通过。

## 短信验证码后备

1. 先在网页点击一个空的短信验证码输入框（单框，不是图形 CAPTCHA）。
2. 打开扩展、输入岗位编号，点击「接收此页验证码」。
3. 去工作台的代填对话框，选择对应的已连接页面，手动输入或明确点击粘贴验证码。
4. 在 2 分钟内收到的本次验证码只传到绑定的标签页、文档与原 URL。关闭扩展弹窗不影响等待；导航、输入框失效、超时则停止。新连接替代旧连接。
5. 代码填入时不触发 input/change 或提交，以免自动登录。受控表单可能需要本人重输一次。验证码只供本人检查继续，不自动发送到所有网页。

不读取剪贴板、不截图、不识别/绕过 CAPTCHA、不读取页面短信。token 只在扩展可信上下文中使用；本地请求禁止重定向、只允许 localhost/127.0.0.1。扩展凭用户点击使用 activeTab 注入，不申请全网后台读取权限。

开发验证：`node --test tests/test_extension_fill.mjs`（从项目根目录）。覆盖字段映射和跳过策略、OTP 绑定状态、导航/DOM 变化、扩展权限、本地地址与凭据防外发；不是对所有招聘网站兼容性的证明。
